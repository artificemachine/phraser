## Step-by-Step Instructions

### Step 1: Create the new phraser icon

1. Design a new 512×512 PNG icon for phraser
2. Save it as `src-tauri/icons/icon.png` (overwrite)
3. From the same design, create `src-tauri/icons/logo.png`

### Step 2: Generate platform icons

```bash
# Install Tauri CLI if not already
bun install

# Regenerate all platform icon sizes from the new icon.png
bunx tauri icon src-tauri/icons/icon.png
```

This will create/update all iOS, Android, and Windows icon files automatically.

### Step 3: Create the .ico and .icns

```bash
# macOS .icns (requires iconutil)
# Create a .iconset folder from icon.png, then:
iconutil -c icns src-tauri/icons/icon.iconset -o src-tauri/icons/icon.icns

# Windows .ico
# Use imagemagick or an online converter to create icon.ico from icon.png
```

### Step 4: Replace tray icons

Create 6 new PNGs at ~22×22px (template icons) showing the phraser logo in three states:

- **idle** — normal logo
- **recording** — logo + red recording dot overlay
- **transcribing** — logo + processing indicator

Each state needs a dark-theme and light-theme variant.

**Dark theme** (for light menu bars — macOS, light Linux themes): use dark-colored logo
**Light theme** (for dark menu bars — dark Linux themes, Windows): use light/white-colored logo

Save to `src-tauri/resources/`:

```
tray_idle.png
tray_idle_dark.png
tray_recording.png
tray_recording_dark.png
tray_transcribing.png
tray_transcribing_dark.png
phraser.png    (same as tray_idle.png for colored/Linux theme)
```

### Step 5: Replace the SVG hand component

Replace `src/components/icons/PhraserHand.tsx` with a new phraser-branded SVG.

Option A — replace the SVG path entirely with a phraser logo/icon:

```tsx
const PhraserHand = ({ width, height }: { width?: number | string; height?: number | string }) => (
  <svg width={width || 126} height={height || 135} viewBox="0 0 126 135" ...>
    {/* New phraser logo SVG paths here */}
  </svg>
);
export default PhraserHand;
```

Option B — rename the component to reflect it's now a phraser logo (not a hand), OR add a separate `PhraserLogo` component and update the imports in `Sidebar.tsx`.

### Step 6: Verify

```bash
# Check no stray handy files remain
find src-tauri -name "*handy*" -o -name "*Handy*"

# Run cargo check to ensure tray.rs references are correct
cd src-tauri && cargo check

# Run frontend tests (Sidebar uses PhraserHand/PhraserTextLogo)
bun run test:unit
```
